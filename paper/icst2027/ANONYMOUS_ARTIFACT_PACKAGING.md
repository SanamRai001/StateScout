# ICST 2027 Anonymous Artifact Packaging

This is the author-side procedure for creating the reviewer-facing StateScout replication package. Do not include this file inside the anonymous reviewer archive.

## Preconditions

- Keep the locally generated `results/raw/` directory.
- Keep `package-lock.json` generated by the verified npm installation.
- Do not put `node_modules/` inside the submitted archive.

## 1. Verify the paper/research state

```powershell
npm run paper:submission-gate
```

Expected: research freeze intact, no missing/uncited bibliography keys, and zero identity leaks.

## 2. Build the anonymous reviewer directory

```powershell
npm run paper:build-anonymous-artifact
```

Default output: `dist/statescout-icst2027-anonymous/`.

The build must report `package-lock.json included: true`, zero identity leaks, protected-content digests, and SHA-256 hashes for the four included controlled-result JSON files.

## 3. Preflight the staged directory

```powershell
npm run paper:preflight-anonymous-artifact
```

Expected:

```text
Required paths missing: 0
Forbidden entries present: 0
paper:* scripts present: 0
Required artifact scripts missing: 0
Artifact manifest valid: true
Controlled-result integrity errors: 0
Identity leaks: 0
Anonymous artifact preflight: PASS
```

## 4. Create the ZIP

```powershell
Remove-Item .\dist\statescout-icst2027-anonymous.zip -Force -ErrorAction SilentlyContinue
Compress-Archive -Path .\dist\statescout-icst2027-anonymous\* -DestinationPath .\dist\statescout-icst2027-anonymous.zip -CompressionLevel Optimal
```

Compress the staged directory before installing dependencies inside it. The submitted ZIP must not contain `node_modules/`.

## 5. Hash the exact ZIP

```powershell
Get-FileHash .\dist\statescout-icst2027-anonymous.zip -Algorithm SHA256
```

Record this SHA-256 with the submission record. Recompute it whenever the ZIP changes.

## 6. Verify from a fresh extraction

```powershell
Remove-Item .\dist\artifact-verify -Recurse -Force -ErrorAction SilentlyContinue
Expand-Archive -Path .\dist\statescout-icst2027-anonymous.zip -DestinationPath .\dist\artifact-verify
Push-Location .\dist\artifact-verify
npm ci
npx playwright install chromium
npm run artifact:smoke
Pop-Location
```

Expected high-level result: strict typecheck passes, 75/75 tests pass, all protected trees match, and `Anonymous research snapshot intact: true`.

## 7. Optional full controlled reproduction

```powershell
Push-Location .\dist\artifact-verify
npm run research:reproduce-controlled
Pop-Location
```

Do not make the external Phase 19 public-site rerun a required acceptance gate.

## 8. Final archive inspection

Confirm that the archive contains no `.git/`, `.github/`, `paper/`, or `node_modules/`; contains no author name, personal GitHub handle/domain, local project path, or public freeze/merge commit identifiers; and contains `README.md`, `package-lock.json`, both research manifests, and the four controlled result JSON files.

## 9. Submission hosting

ICST 2027 Research Papers expect an anonymized replication package with the software, data, and instructions needed to replicate the results.

Use the conference submission system's anonymous supplementary-material mechanism if available, or another anonymous hosting mechanism that does not reveal the author-owned repository/account. Do not link reviewers directly to the author-owned public repository during double-anonymous review.

## 10. License

The initial ICST research-paper CFP requires an anonymized replication package but does not state a specific artifact license requirement. Before archival/public artifact release, choose an explicit project/artifact license; do not silently assign one without the author's decision.

## Final author record

Record the exact manuscript PDF and anonymous artifact ZIP, both SHA-256 values, the artifact manifest hashes, submission date, and venue submission ID.
